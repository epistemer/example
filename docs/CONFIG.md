# confab configuration

Confab, a conference organiser's back office. Generated by cfgx from the schema; don't edit.

Each setting comes from, highest first: a flag, an environment variable, the config file (`confab.yaml`, `.yml` or `.json`, looked for in `.`, or named by `--config` or `CONFAB_CONFIG`), or its default. An empty value counts as not set.

## `log`

Logging.

| Key | Description | Type | Default | Env | Flag | Used by |
|-----|-------------|------|---------|-----|------|---------|
| `log.level` | Minimum log level. | one of `debug`, `info`, `warn`, `error` | `info` | `CONFAB_LOG_LEVEL` | `--log-level` | every command |
| `log.format` | Output format. | one of `text`, `json` | `text` | `CONFAB_LOG_FORMAT` | `--log-format` | every command |
